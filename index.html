What I fixed, and where.

Eight pull requests. Every number below was measured on a named machine against a control, and every one of them is in the merged diff.

merged into google-deepmind/mujoco #3396

Quadratic scratch in island discovery

Native island discovery allocated scratch memory that grew with the square of the tree count. The fix rebuilds the same result with an allocation that grows linearly instead.

84,033,568 bytes to 65,568 at ntree 4,096. 1,281.6x less.

ntree = 4,096, scratch 84,033,568 B to 65,568 B

merged into google-deepmind/mujoco_warp #1541

A linear-memory GPU disjoint-set union

The GPU island-discovery kernel carried the same quadratic memory shape onto the device. A linear-memory disjoint-set union replaces it.

156.738 us to 101.097 us. Scratch 7,929,856 bytes to 180,224.

merged into google-deepmind/mujoco #3450

An inverted point-id table for convex hulls

Convex hull graph construction scanned every pair of points to find a match. An inverted point-id table finds it directly.

16 lines added. 15,361x fewer probes at V=40,962. Cold load 134.400 ms to 71.163 ms.

merged into google/highway #3244

Pruned collisions by slice structure

The collision and scan tests compared key pairs the slice structure had already ruled out. Pruning by structure removes them before the compare ever runs.

894,081,141 comparisons to 13,643,737 at one million keys. 65.5x.

merged into google/XNNPACK #10801

Reusing the leading gap in the memory planner

The memory planner never considered the free gap sitting before the first live block. Reusing that leading gap lowers peak workspace.

MobileNet V1 peak 23.862980 to 22.331730 MiB. Workspace 144 MiB to 112 MiB.

merged into tensorflow/tensorflow #124410

A missing back-propagation in transitive reduction

Transitive reduction was documented as full reachability but never back-propagated, so a redundant control edge with a longer alternate path survived the prune.

Four control edges emitted where the unique transitive reduction is three.
